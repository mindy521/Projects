# 路線 B · 主題生成工作流

適用：不要劇集畫面，或素材不可用；用主題產心理學科普短影音。

## 選引擎

| 條件 | 引擎 |
|---|---|
| 預設／解說＋素材圖＋旁白 | **otopilot** |
| 使用者要「大頭拼貼／大人物故事風」 | **bighead-collage** |
| 數位人 | lanshu（預設拒絕，改建議 A／B） |

## 共同：先寫對內容

1. 依 `writing-rules.md` 定**一個**概念
2. 若牽涉譚松韻劇情：場次仍受分集文件約束；沒有可靠場次就改寫成**純生活例子**，不要硬套劇名
3. 產出：
   - 短片旁白（約 45–75 秒可讀完）
   - 標題（處境＋概念名）
   - 文末兩句界限（臨床／證據）

## B1 · otopilot

1. 開 otopilot 工作區或依其 `AGENTS.md`
2. 建新工作：`node yeni-is.js <slug> --dil zh --format short`（旗標以該專案當版為準；中文介面／語言選項跟 README）
3. **你（agent）直接寫旁白檔**，不要依賴付費腳本 API
4. 補搜尋關鍵字 → 找圖 → 配音 → 合成
5. 出片後可用 **ffmpeg-skill** 做 9:16／響度／平台 check

免費路線重點：腳本自己寫、Edge TTS、CC 圖；商業頻道再考慮付費音色。

## B2 · bighead-collage

1. `python scripts/doctor.py`
2. 首次設定配音／生圖（`config.py`）
3. 給选题＋確認文案 → 導演表 → 素材 → 渲染 → `verify.py`
4. 適合「用一個人物故事講清一個心理機制」；仍遵守本 skill 的禁寫與單一概念

## 何時改回 A

使用者後來提供劇集片段、或說「還是用耿耿那段畫面」→ 停 B，改走 `cut-workflow.md`，旁白可重用。
